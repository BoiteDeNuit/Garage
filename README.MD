Программа Гараж написанная для обучения базовому JAVA языку
функционал программы
1 Добавление машины через билдер(бренд модель код двигателя лошадиные силы год)
2 Просмотр добавленных машин
3 Поиск по коду двигателя
4 Статистика машин
5 Фильтр машин
6 Случайная загрузка N машин
7 Удаление машин по id
0 Выход из меню

Для запуска программы  необходимо в терминале написать
mvn clean
mvn compile
mvn package
mvn dependency:tree
java -jar 

Присутствуют классы Car и пока неиспользуемый Owner
два интерфейса для рефакторинга проекта (к примеру на Spring)
GarageService Выполняющий основную логику
Несколько Exception
